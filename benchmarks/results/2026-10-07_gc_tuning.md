# Garbage Collection Tuning & Tail Latency Benchmark Report

**Date:** 2026-10-07  
**Target:** `matching-engine` service  
**Environment:** Oracle Cloud ARM64 Ampere A1 (2 vCPU, 12 GB RAM)  
**JDK:** OpenJDK 21.0.12 LTS  

---

## 1. Executive Summary

Garbage Collection tuning was conducted on the core `matching-engine` to guarantee that GC pause times do not compromise the exchange's End-to-End P99 latency SLA (< 200 ms).

Key milestones:
1. **Ergonomics Discovery:** Identified that container cgroups under fractional CPU requests demoted HotSpot 21 to `SerialGC` (`UseSerialGC = true`), causing 100ms+ STW pauses.
2. **Evaluation:** Benchmarked `G1GC` vs `Generational ZGC` under 2 vCPU constraints.
3. **Commitment:** Committed tuned G1GC flags (`-XX:+UseG1GC -XX:MaxGCPauseMillis=20 -XX:+ParallelRefProcEnabled -Xms256m -Xmx512m`) to the Helm chart.
4. **Impact:** E2E P99 latency dropped to **130.18 ms** (-56.07% faster than baseline SLA).

---

## 2. Experimental Data & Collector Comparison

| GC Collector | Command Flags | Pause Target | Measured P50 E2E | Measured P99 E2E | CPU Overhead | Recommendation |
|---|---|:---:|:---:|:---:|:---:|:---:|
| **SerialGC** (Default Ergonomic) | None | Unbounded | 211.18 ms | 296.35 ms | Low | **Rejected** (High pause spikes) |
| **Generational ZGC** | `-XX:+UseZGC -XX:+ZGenerational` | < 1 ms | 108.40 ms | 165.20 ms | High (competes with app) | Viable for >= 4 vCPUs |
| **Tuned G1GC** | `-XX:+UseG1GC -XX:MaxGCPauseMillis=20` | < 20 ms | **92.60 ms** | **130.18 ms** | Low / Predictable | **Selected for 2 vCPU production** |

## 3. Configuration Applied

In `infra/helm/dete/values.yaml`:
```yaml
matchingEngine:
  image: dete/matching-engine:latest
  replicaCount: 1
  port: 8084
  jvmArgs: "-XX:+UseG1GC -XX:MaxGCPauseMillis=20 -XX:+ParallelRefProcEnabled -Xms256m -Xmx512m"
```

In `infra/helm/dete/templates/matching-engine/deployment.yaml`:
```yaml
- name: JAVA_TOOL_OPTIONS
  value: {{ .Values.matchingEngine.jvmArgs | default "-XX:+UseG1GC -XX:MaxGCPauseMillis=20 -Xms256m -Xmx512m" | quote }}
```

Verified live on container:
```bash
JAVA_TOOL_OPTIONS=-XX:+UseG1GC -XX:MaxGCPauseMillis=20 -XX:+ParallelRefProcEnabled -Xms256m -Xmx512m
```
